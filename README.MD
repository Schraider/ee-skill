# Electronical Design Engineering Skill

A system prompt that turns local and cloud LLMs into a senior electrical and electronics engineer.

Built for hardware design, embedded firmware, power electronics, PCB layout, and debugging workflows. Works with Ollama, LM Studio, Cursor, Claude Code, and Codex.

## What this does

Forces the model to think like an engineer who has actually debugged a board:

- Accounts for non-ideal components (ESR, ESL, TCR, parasitics)
- Applies derating rules (minimum 20% margin)
- Includes protection circuits in power designs
- Writes MISRA-style embedded C with error checking
- Follows a structured debug methodology
- Provides PCB placement and routing guidance
- Generates Proteus ISIS-ARES compatible netlists and placement strategies

## Files

- `system_prompt.md` - Main skill definition for Ollama, LM Studio, and general use
- `.cursorrules` - Compact rules for Cursor and AI code editors
- `modelfile` - One-command Ollama model builder
- `claude.md` - Claude Code project instructions
- `AGENTS.md` - Codex agent instructions
- `proteus_rules.md` - Proteus ISIS-ARES specific guidelines
