# Proteus ISIS-ARES Guidelines

When asked to help with Proteus PCB design, follow these rules.

## What you can do

You cannot generate .dsn or .pdsprj files directly. Instead, provide:

1. Complete netlist with pin numbers and connections
2. Component placement strategy with coordinates
3. Trace width calculations based on current
4. Routing priorities and constraints
5. ARES design rules (clearance, trace width, via size)
